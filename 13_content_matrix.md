## 1. Content Architecture & Matrix Methodology

This Content Matrix establishes the complete structural inventory for all 50 URLs in the V2 website architecture. Every single page is assigned a precise copy hierarchy, a Generative Engine Optimization (GEO) short-answer snippet target, visual media asset requirements, upward internal link equity rules (enforcing Critical Rule 9), and production approval criteria.

### Key Content Rules:
1. **Zero Placeholder Text**: No `Lorem Ipsum` or generic marketing filler permitted anywhere across the 50 pages.
2. **GEO Snippet Requirement**: Every page includes a dedicated 60–80 word direct answer summary box structured for LLM extraction (ChatGPT, Perplexity, Gemini, Claude).
3. **Upward Link Equity (Critical Rule 9)**: Informational articles, location pages, and case studies MUST channel primary link equity into the 4 commercial Service Pillars, restricting direct `/contact/` links to preserve PageRank.
4. **Single-Practitioner Authenticity**: Every piece of copy reinforces Vraj Vithalani's direct single-practitioner execution model (no junior hand-offs, direct account oversight, GTU diploma background, EKASVA finalist proof).

## 7. Visual Media Asset Requirements Summary

 across the 50-page architecture:
* **Total Image Assets Identified**: **52 Unique WebP Images**
* **Format Standards**: Next.js `<Image>` pre-loaded `.webp` format with explicitly reserved `width` and `height` attributes to prevent Cumulative Layout Shift (`CLS = 0.00`).
* **CDN Distribution**: Uploaded directly via `/iamadmin/media/` to Cloudinary (`/vrajvithalani/production/`) with automatic `f_auto,q_auto` delivery.
* **Mandatory Accessibility**: Every single asset in the matrix includes a required `altText` description for WCAG 2.1 AA compliance and image search indexation.

## 8. Quality Assurance & Approval Workflow

```
[Content Drafting] ──> [GEO Snippet Check (60-80w)] ──> [Rule 9 Link Audit] ──> [Production Approved]
```

1. **Copy Verification**: Confirm 100% single-practitioner authenticity with zero `Lorem Ipsum`.
2. **GEO Validation**: Ensure every page contains a dedicated, structured direct-answer block.
3. **Internal Link Audit**: Verify that articles and location pages channel equity upward to commercial pillars without broken or circular links.
4. **Media Validation**: Confirm that all required WebP image assets are uploaded to Cloudinary with verified alt text.
