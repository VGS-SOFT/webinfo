### Pillar 1: Sticky Mobile Trigger & Dynamic URL-Encoded Context Engine
On mobile viewports (&lt; 768px), standard inline forms require vertical scrolling and multi-field interactions. A sticky bottom bar presents a high-contrast 1-tap WhatsApp trigger button that stays accessible regardless of scroll position.

By dynamically populating the URL `text` query parameter, we pass precise context into the user's WhatsApp chat before they press send:

### Pillar 2: Webhook Routing & Sub-5-Minute Speed-to-Lead Automation
Lead decay research proves that contacting a prospect within **5 minutes** of inquiry increases lead qualification rates by **391%** compared to a 30-minute delay. When using Meta WhatsApp Business API (WABA), inbound messages trigger an immediate serverless HTTP POST webhook to your routing engine:

```typescript
// Next.js App Router Webhook Handler for Meta WhatsApp API
import { NextResponse } from "next/server";

export async function POST(req: Request) {
  const body = await req.json();
  
  // Extract inbound message metadata
  const entry = body.entry?.[0];
  const changes = entry?.changes?.[0];
  const message = changes?.value?.messages?.[0];

  if (message) {
    const senderPhone = message.from;
    const messageContent = message.text?.body || "";

    // 1. Log lead into Supabase PostgreSQL DB
    await saveLeadToDatabase({ phone: senderPhone, message: messageContent });

    // 2. Dispatch instant notification to clinical/sales team Telegram/Slack
    await notifySalesTeam({ phone: senderPhone, message: messageContent });

    // 3. Send automated immediate WhatsApp acknowledgement via Meta API
    await sendWhatsAppAutoReply(senderPhone, "Thank you for reaching out! Our specialist has received your inquiry and will respond within 5 minutes.");
  }

  return NextResponse.json({ status: "success" }, { status: 200 });
}
```

### Pillar 3: Server-Side Meta CAPI & Google Ads Conversion Offset
Because client-side ad blockers often obstruct third-party JavaScript tags, WhatsApp conversion events should be dispatched server-side when a user clicks the trigger link:

```typescript
// Server Action to Log WhatsApp Click Event to Meta CAPI
"use server";

export async function logWhatsAppConversion(userPayload: {
  pageUrl: string;
  userAgent: string;
  ipAddress: string;
}) {
  const metaCapiEndpoint = `https://graph.facebook.com/v19.0/${process.env.META_PIXEL_ID}/events?access_token=${process.env.META_CAPI_TOKEN}`;

  await fetch(metaCapiEndpoint, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      data: [
        {
          event_name: "Lead",
          event_time: Math.floor(Date.now() / 1000),
          action_source: "website",
          event_source_url: userPayload.pageUrl,
          user_data: {
            client_ip_address: userPayload.ipAddress,
            client_user_agent: userPayload.userAgent,
          },
          custom_data: {
            lead_type: "WhatsApp 1-Tap Trigger",
          },
        },
      ],
    }),
  });
}
```

## 8. Frequently Asked Questions (FAQ)

### Why is 1-tap WhatsApp lead capture dramatically more effective on mobile than traditional contact forms?
Over 85% of local commercial search traffic occurs on mobile devices where typing multi-field contact forms introduces severe input friction and accidental typos. A 1-tap WhatsApp trigger immediately opens the user's native app with a pre-filled message, removing friction while capturing real phone numbers.

### What is the technical difference between direct wa.me links and Meta WhatsApp Business API (WABA)?
Direct `wa.me` links open a 1-on-1 chat in the client's WhatsApp application without requiring server infrastructure. Meta WhatsApp Business API (WABA) connects to server-side webhooks, enabling automated round-robin lead assignment, instant auto-replies, and CRM event tracking.

### How does pre-filled message context routing improve sales conversion rates?
URL encoding passes dynamic page context into the user's input box (e.g., *"Hi Vraj, I'm interested in the Knee Pain Physiotherapy package seen on /services/physiotherapy/"*). This equips sales or clinical teams with exact service intent and page origin immediately upon message delivery.

### How does WhatsApp lead automation ensure compliance with Indian DPDP Act 2023 regulations?
WhatsApp lead generation is user-initiated. Because the prospect explicitly taps the trigger button and sends the first message from their verified WhatsApp account, consent is explicit and non-coercive.
