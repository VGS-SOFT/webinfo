## 7. Frequently Asked Questions (FAQ Accordion)

### Q1: Why should I hire an integrated specialist instead of four separate agency teams?
An integrated specialist eliminates the friction and miscommunication between web developers, SEO strategists, and ad managers. Because Vraj Vithalani handles both the web codebase and performance ad campaigns, landing page speed, conversion tracking tags, schema markup, and ad relevance scores are synchronized seamlessly without waiting on third-party developers.

### Q2: What is the typical engagement process and onboarding timeline?
Onboarding begins with a 30-minute discovery consultation followed by a comprehensive audit of your current digital footprint. Upon agreement, technical SEO and ad campaign setups take 3–5 business days, while complete Next.js custom website builds typically require 2–4 weeks. You communicate directly with Vraj throughout every phase.

### Q3: How do you handle tracking, conversion attribution, and data privacy?
Tracking is implemented using Google Tag Manager (GTM), GA4, Meta Conversion API (CAPI), and Microsoft Clarity. All forms comply with India's DPDP Act 2023, utilizing hashed user identifiers and client-side honeypot traps to ensure zero spambot pollution in your analytics dashboard.

### Q4: What industries and business types do you specialize in?
Engagements focus heavily on high-intent B2B services, industrial manufacturing, healthcare practices, e-commerce brands, and local enterprise service providers across Surat, Ahmedabad, Bangalore, and global remote clients.

### Q5: What minimum budget is required to begin working together?
To ensure measurable return on investment, recommended ad budgets start at ₹25,000/month for Google Ads management. Web development and technical SEO projects are scoped on a custom milestone basis depending on system complexity.

### Q6: Do I maintain 100% ownership of my ad accounts, domain, and codebase?
Yes, absolutely. You maintain full administrative ownership of your Google Ads accounts, Google Tag Manager containers, domain names, Cloudinary media vaults, and GitHub code repositories at all times.

## 8. Main Lead Capture Form (HTML/JSX Component Code)

```tsx
import React, { useState } from 'react';

export default function LeadCaptureForm() {
  const [formData, setFormData] = useState({
    fullName: '',
    email: '',
    phone: '',
    serviceCategory: 'google-ads',
    budgetBracket: '25k-50k',
    projectDetails: '',
    website_url: '' // Anti-spam honeypot field
  });

  const [status, setStatus] = useState<'idle' | 'submitting' | 'success' | 'error'>('idle');

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    setStatus('submitting');

    try {
      const res = await fetch('/api/leads/submit/', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(formData)
      });

      if (res.ok) {
        setStatus('success');
      } else {
        setStatus('error');
      }
    } catch (err) {
      setStatus('error');
    }
  };

  return (
    <section className="bg-slate-900 text-white py-16 px-6 rounded-2xl max-w-4xl mx-auto my-12 shadow-2xl">
      <div className="text-center mb-10">
        <h2 className="text-3xl font-bold mb-3">Initiate Your Growth Audit</h2>
        <p className="text-slate-300">Direct consultation with Vraj Vithalani. Response guaranteed within 24 hours.</p>
      </div>

      {status === 'success' ? (
        <div className="bg-emerald-900/50 border border-emerald-500 text-emerald-200 p-6 rounded-xl text-center">
          <h3 className="text-xl font-bold mb-2">Inquiry Received Successfully</h3>
          <p>Thank you. Vraj Vithalani will review your information and respond within 24 business hours.</p>
        </div>
      ) : (
        <form onSubmit={handleSubmit} className="space-y-6">
          {/* Invisible Anti-Spam Honeypot Field */}
          <div className="hidden" aria-hidden="true">
            <label htmlFor="website_url">Do not fill this out if you are human</label>
            <input
              type="text"
              id="website_url"
              name="website_url"
              tabIndex={-1}
              value={formData.website_url}
              onChange={(e) => setFormData({ ...formData, website_url: e.target.value })}
            />
          </div>

          <div className="grid grid-cols-1 md:grid-cols-2 gap-6">
            <div>
              <label className="block text-sm font-medium mb-2">Full Name *</label>
              <input
                type="text"
                required
                className="w-full bg-slate-800 border border-slate-700 rounded-lg px-4 py-3 text-white focus:outline-none focus:border-teal-500"
                value={formData.fullName}
                onChange={(e) => setFormData({ ...formData, fullName: e.target.value })}
              />
            </div>
            <div>
              <label className="block text-sm font-medium mb-2">Email Address *</label>
              <input
                type="email"
                required
                className="w-full bg-slate-800 border border-slate-700 rounded-lg px-4 py-3 text-white focus:outline-none focus:border-teal-500"
                value={formData.email}
                onChange={(e) => setFormData({ ...formData, email: e.target.value })}
              />
            </div>
          </div>

          <div className="grid grid-cols-1 md:grid-cols-2 gap-6">
            <div>
              <label className="block text-sm font-medium mb-2">Phone / WhatsApp *</label>
              <input
                type="tel"
                required
                className="w-full bg-slate-800 border border-slate-700 rounded-lg px-4 py-3 text-white focus:outline-none focus:border-teal-500"
                value={formData.phone}
                onChange={(e) => setFormData({ ...formData, phone: e.target.value })}
              />
            </div>
            <div>
              <label className="block text-sm font-medium mb-2">Primary Service Interest *</label>
              <select
                className="w-full bg-slate-800 border border-slate-700 rounded-lg px-4 py-3 text-white focus:outline-none focus:border-teal-500"
                value={formData.serviceCategory}
                onChange={(e) => setFormData({ ...formData, serviceCategory: e.target.value })}
              >
                <option value="google-ads">Google Ads Performance Management</option>
                <option value="technical-seo">Technical SEO & GEO Optimization</option>
                <option value="web-development">Next.js Web Development</option>
                <option value="cro-automation">CRO & Lead Automation</option>
                <option value="full-stack">Full-Stack Growth Engineering</option>
              </select>
            </div>
          </div>

          <div>
            <label className="block text-sm font-medium mb-2">Monthly Budget Bracket *</label>
            <select
              className="w-full bg-slate-800 border border-slate-700 rounded-lg px-4 py-3 text-white focus:outline-none focus:border-teal-500"
              value={formData.budgetBracket}
              onChange={(e) => setFormData({ ...formData, budgetBracket: e.target.value })}
            >
              <option value="25k-50k">₹25,000 - ₹50,000 / month</option>
              <option value="50k-1L">₹50,000 - ₹1,00,000 / month</option>
```
